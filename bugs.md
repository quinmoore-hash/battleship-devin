Severity: **P0** game unplayable / crash · **P1** wrong game result or blocked flow · **P2** visual/audio glitch, wrong feedback · **P3** polish, nit.

Status: `open` → `in-progress` → `fixed` (link the PR) · `wontfix` with a reason.
